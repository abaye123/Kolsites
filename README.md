# Kolsites

תוכנת קיוסק לעמדות מחשב ציבוריות, מבוססת WebView2 ו-WinUI 3. מציגה כפתור צף תמיד-למעלה שפותח חלון מסך מלא עם רשימת אתרים ניתנת להגדרה — הכל מוגן מפני יציאה, עם מקלדת וירטואלית, ניטור אינטרנט ו-Watchdog שמפעיל מחדש אוטומטית.

מתאים לעמדות עם דפי טפסים מקוונים (תרומות, פניות, רישומים) שצריכות להישאר נעולות על זרימת השימוש בלבד, בלי שמשתמשים יוכלו לצאת לדפדפן או למערכת ההפעלה.

## ✨ תכונות עיקריות

### תצוגה ומסך
- **כפתור צף תמיד-למעלה** — נשאר מעל כל החלונות במערכת (כולל אפליקציות מסך מלא), בלי להופיע ב-Alt+Tab או ב-taskbar
- **חיווי טעינה על הכפתור הצף** — בעת לחיצה מוצג ProgressRing במקום האייקון, והכפתור מוסתר רק אחרי שחלון הקיוסק כבר עלה למסך — בלי "רגע ריק" שמבלבל את המשתמש
- **חלון קיוסק מסך מלא** — נפתח בלחיצה על הכפתור, ללא מסגרת ובלי דרך פשוטה לצאת
- **מצב "חלון רגיל" (ללא כפתור צף)** — אופציה להפעיל את התוכנה ישר כחלון דפדפן רגיל עם title bar ו-X של מערכת. סגירה ב-X מסיימת את התהליך. במצב הזה אין always-on-top, אין מסך מלא, אין סגירה אוטומטית לאחר חוסר פעילות, וה-Watchdog לא מקפיץ מחדש (מוצב דגל 'כיבוי ידני' בסגירה). שימושי בעמדות שצריכות לתת למשתמש שליטה רגילה על החלון
- **מצב כהה/בהיר/לפי המערכת** — ברירת מחדל עוקבת אחר הגדרות Windows
- **תמיכה ב-RTL** — ממשק מלא בעברית

### ניהול האתרים
- **רשימת אתרים מוגדרת מראש** — שבעה אתרים דיפולטיים (לדעת, דרשו, שיח התורה, שיננא, ישיבה על קברו, רב קו, תורה שבכתב), ניתנים לעריכה והוספה
- **סקריפטים מותאמים לכל אתר** — הזרקת JavaScript אוטומטית כל שנייה כדי להסיר לוגואים, תפריטים, פרסומות וכפתורים שלא רצויים בעמדה ציבורית
- **חסימת כרטסת נטפרי גלובלית** — סקריפט ברירת מחדל שמוזרק לכל אתר ומסיר את כרטסת התשלום של נטפרי לפני שהיא מספיקה לטעון (`MutationObserver` שתופס את תגי ה-script והאלמנטים בזמן הוספתם ל-DOM)

### חסימות והגנה
- **חסימת ניווט לאתרים חיצוניים** — לחיצה על קישור באתר תעבוד רק אם ההוסט שלו זהה (או תת-דומיין) להוסט של הכפתור שנבחר. משאבים בתוך הדף (CSS/JS/iframes/AJAX) ממשיכים להיטען רגיל. במקרה של חסימה - הדף המקורי נטען מחדש כדי למנוע מסך לבן
- **חסימה קבועה של סכמות חיצוניות** — `mailto:`, `tel:`, `callto:`, `sms:`, `skype:`, `whatsapp:` — לא יוכלו לצאת לאפליקציות חיצוניות מתוך הקיוסק
- **חסימת תפריט הקשר ימני** ו-DevTools, בלי דרך פשוטה לפתוח כתובת אחרת
- **טווחי זמן חסומים** — אפשרות להגדיר ימים ושעות שבהם הכפתור הצף לא יפתח את הקיוסק. במקום זה מוצג חלון "התוכנה לא פעילה כרגע" עם מונה דקות עד החזרה לפעילות; הטווחים תומכים גם בחציית חצות

### מקלדת ונגישות
- **מקלדת וירטואלית** — תמיכה בעברית ואנגלית (גדולות וקטנות) ומספרים, עם הקלדה ישירה לתוך שדות באתר הטעון
- **גודל מקלדת מתכוונן** — רגיל / גדול / גדול מאוד / ענק. שימושי במסך לאורך, שאז יש מקום לגובה גדול יותר ומקשים גדולים נוחים יותר למגע
- **פתיחה אוטומטית של המקלדת** — אופציה לפתוח את המקלדת אוטומטית כשפקד קלט בדף האינטרנט מקבל פוקוס

### יציבות וניטור
- **ניתוק אוטומטי לאי-פעילות** — לאחר 45 שניות ללא קלט (עכבר/מגע/מקלדת) החלון נסגר וחוזר לכפתור הצף, מנקה cache בדרך
- **ניטור אינטרנט** — בדיקת ping כל 5 שניות, עם אפשרות להציג overlay מסך מלא או רק badge דיסקרטי בסרגל
- **Watchdog Service** — משימה מתוזמנת ב-Task Scheduler שמוודאת כל דקה שהתוכנה רצה, ומפעילה מחדש אוטומטית אם נסגרה
- **ניקוי cache אוטומטי** בעת סגירת הקיוסק — להגנה על פרטיות המשתמש הבא

### גישה מנהלתית
- **חלון הגדרות נפרד** — לעריכת רשימת האתרים, הסקריפטים, מיקום הכפתור הצף ושאר ההגדרות
- **קיצור גישה מהירה להגדרות** — לחיצה כפולה על לוגו התוכנה בחלון "אודות" של הקיוסק פותחת בקשת סיסמה ומאפשרת לפתוח את ההגדרות בלי לסגור את הקיוסק. הקיצור מנוטרל אם לא מוגדרת סיסמה
- **סיסמת מנהל מוצפנת** — הסיסמה נשמרת מוצפנת ב-PBKDF2-HMAC-SHA256 עם מלח אקראי (100,000 איטרציות), אף פעם בטקסט גלוי
- **נעילת brute-force** — אחרי 3 נסיונות שגויים ברצף, הגישה להגדרות נחסמת ל-30 דקות. הנעילה נשמרת לדיסק ועמידה גם לאחר סגירה ופתיחה של הקיוסק

## 📥 התקנה

1. הורד את `Kolsites-Setup-1.4.0.exe` מ-[דף ה-Releases](https://github.com/abaye123/Kolsites/releases)
2. הרץ את המתקין (דורש הרשאות אדמין — מתקין לכל המשתמשים במחשב)
3. בזמן ההתקנה אפשר לבחור:
   - קיצור דרך לכפתור הצף על שולחן העבודה
   - קיצור דרך להגדרות על שולחן העבודה
   - הפעלה אוטומטית בעלייה (מומלץ לעמדת קיוסק)
   - התקנת Watchdog שיפעיל את התוכנה מחדש אם תיסגר (מומלץ)
4. אם **Windows App Runtime 1.7** חסר, המתקין יתריע ויפנה לדף ההורדה של Microsoft

### דרישות מערכת

- Windows 10 build 17763 (1809) ומעלה, או Windows 11
- .NET 8 Desktop Runtime
- Windows App Runtime 1.7
- WebView2 Runtime (מותקן אוטומטית בכל Windows מודרני)

## 🚀 שימוש

### שימוש רגיל
לאחר ההתקנה הכפתור הצף מופיע באחת מפינות המסך (דיפולטית למעלה-שמאל). לחיצה על הכפתור פותחת את חלון הקיוסק עם רשימת האתרים. בחירת אתר טוענת אותו במסך מלא.

לאחר 45 שניות ללא פעילות החלון נסגר אוטומטית, מנקה cache, וחוזר לכפתור הצף. אפשר גם לסגור ידנית בכפתור הסגירה.

### מצב "ללא כפתור צף"
אפשר להפעיל בהגדרות → "מצב חלון רגיל (ללא כפתור צף)", או דרך שורת פקודה עם `--no-floating-button`. במצב הזה הפעלת התוכנה פותחת ישר את חלון הדפדפן כחלון רגיל עם title bar ו-X של מערכת. סגירה ב-X מסיימת את התהליך לחלוטין — בלי שירות שמקפיץ אותה מחדש (מוצב דגל 'כיבוי ידני' באופן אוטומטי). הכפתור הצף, ה-always-on-top, מסך מלא, וטיימר חוסר-הפעילות (45ש) — כולם מנוטרלים.

### חלון ההגדרות
פתח את "הגדרות Kolsites" מתפריט התחל או משולחן העבודה. אפשר לערוך:
- **רשימת אתרים** — להוסיף, להסיר, לשנות סדר, להעלות אייקון מותאם, לבחור צבע רקע
- **סקריפטים לכל אתר** — JavaScript שירוץ כל שנייה על האתר (להסרת אלמנטים, חסימת פעולות וכו')
- **מקלדת וירטואלית** — הפעלה/השבתה, בחירת שפה דיפולטית, גודל מקשים, ופתיחה אוטומטית בעת פוקוס על שדה
- **מיקום הכפתור הצף** — אחת משמונה פוזיציות סביב המסך
- **גודל הכפתור הצף** ומרווח מקצה המסך
- **מצב כהה/בהיר/לפי המערכת**
- **התנהגות בעת ניתוק אינטרנט** — overlay מסך מלא או badge קטן
- **סיסמה לפתיחת ההגדרות מהקיוסק** — הסיסמה נשמרת מוצפנת; ריק = הקיצור מנוטרל
- **טווחי זמן חסומים** — הוספת ימים ושעות שבהם התוכנה תהיה לא-פעילה למשתמש
- **מצב חלון רגיל (ללא כפתור צף)** — הפעלת התוכנה תפתח ישר את חלון הדפדפן עם X של מערכת. סגירה ב-X תסיים את התהליך

### גישה להגדרות מתוך הקיוסק
אם מוגדרת סיסמה, אפשר לפתוח את ההגדרות גם בלי לצאת מהקיוסק:
1. בחלון הקיוסק, פתח את חלון ה-"אודות"
2. בצע **לחיצה כפולה מהירה** על לוגו התוכנה
3. הקלד את הסיסמה — חלון ההגדרות ייפתח בתהליך נפרד והקיוסק ייסגר
4. אחרי 3 נסיונות שגויים ברצף הגישה תיחסם ל-30 דקות

### שורת פקודה
```
Kolsites.exe                       # מצב רגיל - כפתור צף
Kolsites.exe --no-floating-button  # פתיחה ישירה של חלון הקיוסק כחלון רגיל (עוקף את ההגדרה)
Kolsites.exe --settings            # פתיחת חלון ההגדרות
Kolsites.exe --watchdog            # מצב Watchdog (חד-פעמי)
Kolsites.exe --watchdog --loop     # Watchdog רציף (כל 30 שניות)
```

## 💾 מיקומי קבצים

- **הגדרות**: `%APPDATA%\Kolsites\settings.json`
- **מצב נעילת סיסמה**: `%APPDATA%\Kolsites\auth_state.json` (FailedAttempts + LockedUntil)
- **יומן שגיאות**: `%APPDATA%\Kolsites\errors.log`
- **יומן Watchdog**: `%APPDATA%\Kolsites\watchdog.log`
- **WebView2 UserData**: `%APPDATA%\Kolsites\WebView2\` (מנוקה אוטומטית בעת סגירת הקיוסק)
- **התוכנה**: `C:\Program Files\Kolsites\`
- **משימת Watchdog**: `Task Scheduler → Kolsites Watchdog` (רצה כ-SYSTEM כל דקה)

## 🔧 פתרון בעיות

**"Windows App Runtime לא מותקן"** — הורד והרץ את [המתקין של Microsoft](https://aka.ms/windowsappsdk/1.7/latest/windowsappruntimeinstall-x64.exe) ואז הרץ שוב את Kolsites.

**הכפתור הצף לא מופיע מעל אפליקציה במסך מלא** — חלק מהאפליקציות (משחקים, נגני וידאו) חוסמות חלונות topmost. סגור אותן או הוצא אותן ממצב מסך מלא.

**הכפתור הצף הוסתר בטעות** — Watchdog יפעיל מחדש את התוכנה תוך כדקה. אפשר גם להפעיל ידנית מקיצור הדרך.

**שינויים בהגדרות לא נכנסים לתוקף** — סגור את הכפתור הצף (דרך Task Manager — `Kolsites.exe`) והפעל מחדש. הקיוסק קורא את ההגדרות בעת ההפעלה.

**Watchdog מפעיל את התוכנה כל דקה במקום פעם אחת** — בדוק את `%APPDATA%\Kolsites\watchdog.log`. אם רואים "הופעל מופע חדש" שוב ושוב, ייתכן שהתוכנה קורסת בעלייה — בדוק את `errors.log`.

**להסרת ה-Watchdog ידנית**: `schtasks /Delete /TN "Kolsites Watchdog" /F`

**שכחתי את סיסמת המנהל / נחסמתי לזמן ארוך** — מחק את `%APPDATA%\Kolsites\auth_state.json` (לאיפוס מונה הנעילה) או ערוך את `settings.json` ושנה את `KioskSettingsPassword` למחרוזת ריקה. אם אין גישה למחשב מתחת לקיוסק, אפשר להגיע אליו דרך Task Manager או SSH/RDP מנהלתי.

**הקיוסק נסגר כשפותחים הגדרות מתוך 'אודות'** — זו ההתנהגות המכוונת. הקיוסק תמיד-למעלה והיה מסתיר את חלון ההגדרות, אז הוא נסגר כשהגישה מאומתת. אפשר לחזור אליו בלחיצה על הכפתור הצף.
